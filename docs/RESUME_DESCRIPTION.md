# Как описывать проект в резюме

## Пока BERT не обучен на BANKING77

**Banking BERT Lab | PyTorch, Transformers, scikit-learn, Python**

«Разработала учебный ML-проект для классификации банковских обращений: подготовка выборок BANKING77, baseline TF-IDF + Logistic Regression, собственный PyTorch train loop для дообучения BERT, расчёт Accuracy и macro-F1, анализ ошибок и интерфейс для локального инференса. Добавила автоматические тесты и GitHub Actions. Дообучение на реальном датасете и сравнение итоговых метрик требуют отдельного запуска».

## После собственного успешного запуска BERT

«Реализовала и запустила дообучение небольшой BERT-модели для классификации банковских обращений на PyTorch без готового Trainer: подготовила train/validation/test, организовала DataLoader, оптимизатор AdamW и цикл обучения. Сравнила модель с TF-IDF + Logistic Regression по macro-F1 и accuracy; исследовала ошибки классификации, сохранила модель для локального инференса».

Добавь **только фактически полученные** значения и не пиши про production/MLOps, GPT fine-tuning или Spark/Hadoop в этом проекте.

## Короткая версия для HH / профиля «Школы 21»

«ML-проект по классификации банковских обращений на PyTorch и BERT: собственный цикл обучения, сравнение с классической моделью, macro-F1, анализ ошибок, тесты и API».
